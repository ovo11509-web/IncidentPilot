# UI 契约：B 风格首阶段

## 路由与导航

- `/admin/workbench`：新增管理员值班首页，后台默认及管理员登录后入口。
- `/admin/incidents`：既有列表，导航称事件中心。
- `/admin/incidents/:incidentId`：既有详情；提案链接携带真实actionId和`#actions`，数据到达后聚焦所选动作，不自动操作。
- `/admin/workbench#pending`：真实待审批区域，更多事件通过事件中心查看。
- `/admin/dashboard`和平台配置地址保留；普通用户仍到/chat。角色判断使用已加载实际user role。

原知识文档搜索保持实际用途，不宣称全局事件/服务搜索。无实现的Runbook/演练GUI不加菜单。

## 主题与品牌

公共外壳及首页/Incident四页采用B深色范围主题；旧配置内容不受全局通用类替换影响。显示IncidentPilot与自有简单SVG，提供nageoffer/ragent和Apache-2.0归属；来源GitHub Stars不标为本项目指标，LICENSE/源码头保留。

装饰不得遮挡内容或截获鼠标，动态效果服从prefers-reduced-motion。实际检查文字对比度、键盘焦点，状态兼具文字/图标。

## 数据与交互

概念图数字、假ID、标题、流程事实不复制。四卡和曲线来自同次响应，标明单位、真实时间与模拟处置范围。窗口起止及显式时区可读；错误/空/加载分开，保留旧值时标旧时间/更新中。

关注列表显示完整真实事件ID、生命周期、动作摘要和时间，不推测标题。最近活动用固定类型文本，未知类型中性显示。待审批状态不保证可批准，完整校验仍在详情。

流程摘要关联所选诊断/Action；无记录显示缺失，有多动作标明所选ID。诊断不等于确认根因，执行成功不等于Incident解决，UNKNOWN不增加写重试。

## 回归

四视口、长ID/证据、滚动折叠、键盘、旧配置弹窗/表格；分页、诊断选择、过期/失效/冲突、独立批准/拒绝、UNKNOWN、登录退出、原轮询及Abort规则。
