# 功能规格：事件复盘与处置手册中心

**功能分支**：`feature/incident-platform`
**创建日期**：2026-10-11
**状态**：用户授权实施
**输入**：先做推荐的事件复盘报告，再做 Runbook 处置手册中心，后续集中调整。

## 用户场景与测试（必填）

### 用户故事 1 - 查看并导出事件复盘（优先级：P1）

管理员从事件详情进入只读复盘，按事实、候选诊断、审批和执行结果回顾事件，并下载本地 Markdown 报告。
**优先级理由**：让既有告警到处置链路留下可阅读成果。
**独立测试**：多页告警/诊断/时间线均被采集，未知执行结果保持 UNKNOWN。
**验收场景**：
1. **Given** 已有事件及多页记录，**When** 查看复盘，**Then** 展示采集范围及真实记录，候选解释不算确认根因，动作成功不算事件解决。
2. **Given** 采集中记录变化、请求失败或达到读取上限，**When** 查看报告，**Then** 明确提示并禁止不完整导出；刷新可重新采集。
3. **Given** 未解决事件或失效诊断，**When** 导出，**Then** 保留状态与历史适用性，导出不改变事件与审批。

### 用户故事 2 - 浏览版本化 Runbook（优先级：P2）

管理员从侧栏查看当前打包手册，搜索标题/范围，查看版本、有效期、来源、完整正文和可核对的章节；从诊断引用跳转到精确版本。
**优先级理由**：让已有证据语料成为可阅读的专业内容。
**独立测试**：五类现有手册显示真实元数据/正文；缺失版本不得回退为最新版。
**验收场景**：
1. **Given** 已校验的模拟语料，**When** 浏览手册，**Then** 明确模拟来源，显示范围及章节行号。
2. **Given** 历史引用指向已不存在版本或摘要不同，**When** 跳转，**Then** 告知不匹配并保留诊断中的历史原文，不把当前正文替换为历史证据。
3. **Given** 普通用户或语料不可用，**When** 读取，**Then** 分别拒绝越权或报告不可用，不伪造空目录。

### 边界情况

- 分页游标不前进、重复身份、跨事件记录、取消旧请求：中止错误采集。
- 大事件：最多1000告警、200诊断、5000时间线、200动作；超限停止完整报告，保留详情入口。
- 报告采用跨请求采集，显示开始/结束时间及复核结果，不宣称事务快照或长期归档。
- Runbook 过期、撤回、非当前版本：可读历史但不宣称可用于处置；范围匹配仍由诊断后端判断。

## 需求（必填）

### 功能需求

- **FR-001**：管理员从事件详情进入复盘，显示事件状态与完整分页事实。
- **FR-002**：报告区分事实、候选解释、审批、执行回执及未解决事项，不自动生成确认根因。
- **FR-003**：复核采集期间事件、动作及时间线变化；失败、截断或变化禁止导出。
- **FR-004**：本地 Markdown 导出仅包含明确选择的展示字段；无原始告警载荷、认证凭据、票据或模型思维链。
- **FR-005**：提供只读手册目录/正文/章节、搜索、版本与有效期，注明模拟来源。
- **FR-006**：诊断与报告引用链接携带手册版本及摘要，缺失或不匹配不回退；历史引用原文继续显示。
- **FR-007**：服务器在读取语料前验证管理员身份；不可用时返回明确失败。
- **FR-008**：沿用 B 主题、键盘焦点和窄屏布局，提供加载、失败、空记录与刷新状态。

### 关键实体

- 复盘采集：现有 Incident、Alert、Diagnosis、Action、Timeline 的只读组合及时间范围，不新增持久化实体。
- 手册版本：已校验的打包语料、文档摘要、范围及章节。

## 成功标准（必填）

### 可度量结果

- **SC-001**：管理员能从事件详情到复盘，再导出包含分页后记录的报告。
- **SC-002**：变更/截断/游标异常/跨事件/取消等自动化用例阻止错误导出。
- **SC-003**：五类打包手册正文和章节与语料一致，非管理员拒绝发生在语料读取前。
- **SC-004**：聚焦 Java 与前端检查、TypeScript、lint 和生产构建实际执行，浏览器检查另列证据。

## 假设

- 用户本轮批准上述两项推荐；首版只读，不含在线编辑、报告保存/签署、反向全局引用统计、故障演练 GUI、生产手册/模型或新依赖。
- 已有安全人员查询 API 继续作为报告数据来源。上游署名、安全审批和 UNKNOWN 协议保持。
