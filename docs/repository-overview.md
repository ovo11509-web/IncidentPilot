# 仓库概览（兼容入口）

项目已采用文档驱动的上下文管理方式。为避免本文件与详细文档重复并逐渐失真，请从以下入口读取：

- 项目目标、当前能力、技术栈、关键目录和开发阶段：`docs/PROJECT_CONTEXT.md`
- 系统架构、模块职责、调用关系、数据流和关键接口：`docs/ARCHITECTURE.md`
- 已确认且需要长期保留的技术决策：`docs/DECISIONS.md`
- 当前、后续和已完成任务：`docs/TODO.md`
- 排错经验、踩坑记录和临时技术说明：`docs/NOTES.md`
- 开发环境和测试命令：`docs/development/`

根目录 `AGENTS.md` 是跨编码工具共享的规则入口，`.specify/` 与
`.agents/skills/speckit-*` 是功能规格、计划、任务和实施工作流的唯一 Spec Kit 集成。
