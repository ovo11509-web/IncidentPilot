## 版本说明草案

IncidentPilot 是基于 `nageoffer/ragent` 改造的 Java AI 运维事件响应作品项目。`v0.1.0` 的说明范围是已有本地证据支持的“告警到安全模拟处置”主链，以及支持学习、演示和复核的界面与工程工具。保留 [Apache-2.0 许可证](../../LICENSE)、[NOTICE](../../NOTICE)、上游署名与原仓库历史。

| 能力 | 贡献归属与说明 |
| --- | --- |
| RAG / Agent、模型路由、知识入库、MCP 桥接及原有管理功能 | 主要继承上游，不表述为从零实现 |
| 告警与 Incident | 新增 HMAC 接入、数据库幂等、关联聚合、状态转换、追加式 Timeline、Outbox 与恢复 |
| 安全响应主链 | 新增诊断证据快照、显式 Action 提案、服务端人工审批、一次性票据、幂等模拟执行、结构化回执及 UNKNOWN 对账 |
| 值班工作界面 | 新增值班工作台、事件操作、B 视觉方案、复盘导出与版本化处置手册；保留既有管理入口 |
| 可观测与验证 | 新增主链关联、默认关闭的短时 Trace、六类本地故障实验、确定性门禁及可靠性证明 |
| 本机交付 | 新增独立持久演示生命周期、源码候选与校验、本机门禁和 CI 定义；CI 定义不等于托管运行通过 |

本机演示使用五类模拟 Runbook、受约束检索与诊断规则以及隔离模拟资源。诊断是有依据的建议，不是现场根因确认；执行成功不会自动关闭事件。真实模型质量、生产处置能力和生产可靠率没有由这些结果获得证明。完整贡献与配置边界见 [项目上下文](../PROJECT_CONTEXT.md) 和 [配置边界](configuration-boundary.md)。

## 本地失败回退草案

本节适用于未来新隔离演示实例的失败收尾，**不是已验收的生产回滚方案**。本轮没有Start/Stop、替换制品或回退操作。

运行前记录候选及制品摘要、独立Name/instanceId、原资源和私有文件摘要；私有凭据留在接收者本机。新演示使用新目录、新配置和新数据库，禁止直接升级旧实例或覆盖其卷。

如果构建或前置检查失败，保留实际退出码与失败记录，停止依赖该结果的后续步骤。如果告警、审批或执行结果不明确，先停止新副作用请求并只读核对；UNKNOWN不盲目重试，不重复批准，不直接调用MCP来凑成功。失败记录不能由后续成功覆盖。

已启动的自有实例按 [本机演示说明](../development/local-demo.md) 核对同一Name所有权后正常Stop，只结束其自有进程/容器，保留五个卷、私有配置和证据；核对旧资源保持且没有额外卷。停止后的URL不作为可用预览地址。不得全局prune、删卷、清库或手工改写进程身份文件。

若以后需要恢复旧演示，先核对其原身份、制品、配置与数据，另按原入口操作；不复制旧四卷模板覆盖新五卷实例，不通过仅替换JAR来假定Schema兼容。没有备份恢复或迁移演练记录时，不承诺数据级回退成功。
