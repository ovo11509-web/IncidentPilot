# 交付候选配置与归属边界

本说明针对 `v0.1.0` 本地交付候选。候选保存经审查的源码原始字节，不把打包过程当作
配置迁移或生产加固；[NOTICE](../../NOTICE) 是 IncidentPilot 新增的来源与修改说明，
[LICENSE](../../LICENSE) 保留上游 Apache-2.0 正文。

## 可分发源码配置

| 路径 | 已核对内容及用途 | 接收者要求 |
| --- | --- | --- |
| `frontend/.env` | 两个公开构建变量；API 使用相对路径，另一个为应用名，不含登录凭据 | 允许作为明确白名单构建输入；新增变量须重新审查 |
| `bootstrap/src/main/resources/application.yaml` | 环境变量引用、上游本地开发数据库/Redis/存储示例及可选服务地址；当前没有追加本机演示账户 | 不是生产配置；不要把开发示例凭据用于真实服务 |
| `mcp-server/src/main/resources/application.yml` | 上游本地数据库示例及应用配置；安全模拟的运行参数由本机入口生成 | 不可直接指向生产资源运行模拟处置 |
| `resources/docker/` | 保留上游可选组件示例；固定开发默认值、环境变量引用与占位值不代表已经部署 | 不属于本候选承诺的启动流程；启用前应单独配置、审查并验证 |
| `resources/docker/graphrag/.env.example` | 上游模板；包含示例数据库密码与模型密钥占位 | 允许分发模板；接收者填写后的 `.env` 必须保持私有 |
| `resources/local-demo/compose.yaml` | 仅使用必填环境参数，不保存本机生成密码 | 通过本机生命周期入口使用，不复制他人的 `compose.env` |

模型、搜索、OSS 等环境变量引用及供应商地址不代表启用了真实调用。此候选的实际演示
范围仍以 [本机演示说明](../development/local-demo.md) 为准：关闭真实模型、普通远程
MCP 与 Broker，仅允许受保护的安全模拟资源。

## 必须由接收者现场生成的私有材料

接收者在自己的新目录执行 `scripts/local-demo.ps1 -Command Init`，生成随机演示账号、
数据库和服务凭据，以及独占资源与配置。密码只在本机私有目录查看，不发送到聊天、
截图或发布材料。不得从作者机器复制以下内容：

- `bootstrap/target/local-demo/` 下的 `credentials.json`、`compose.env`、`app.properties`、
  `mcp.properties`、进程身份、运行日志及业务核验记录。
- 所有 `target/`、`node_modules/`、`dist/`、数据库卷与原始测试报告。
- `.claude/`、`.idea/`、`.vscode/`、本地 `.env` 覆盖、用户 Maven 设置、私钥及证书容器。

`frontend/.env` 与指定的 `.env.example` 是经审查的源码白名单例外；这不构成允许分发其他
同名配置或允许忽略未来修改的授权。

## 历史与安全摘要

当前工作区含未提交及未跟踪的新增实现，源码快照必须覆盖这些文件。仅打包基线 Git
历史不包含当前未提交实现，也不代表已经形成 `v0.1.0` 提交或 Tag。接手恢复应按候选
清单验证原始字节，不能用 `git archive HEAD` 代替完整源码。

源码快照排除本地工具配置，不会自动移除 Git 历史中的同名文件。候选创建时需对可达
历史中的私钥头与可识别令牌做窄规则检查；发现候选阻断项时不得默认分发 bundle。
这类检查只覆盖声明的规则，不构成全仓、历史或生产环境的完整秘密扫描认证。

2026-10-17 实际预检结果：当前待分发源码的私钥头与可识别令牌窄规则检查无命中；
可达历史共检查 17,870 个对象、5,449 个 blob，读取 67,000,659 字节。旧
`src/main/resources/application.yaml` 的 16 个历史 blob 中存在两种完整 `sk-` 形态
`api-key` 字面量，不能确认其有效、已撤销或纯属示例；另一个 README 历史 blob 中的
同类形态为重复字符占位。没有调用这些值，也未联网验证。

因此本次源码候选**不包含 Git bundle**。原有历史完整保留在原仓库，候选只记录基线
HEAD、分支和上游来源；不改写、删除或自动清洗历史。历史移交与疑似凭据处置须另行
决定，当前源码候选不能冒充已经完成保留历史的完整移交。

历史 `.claude/settings.local.json` 的 17 个 blob 只有工具 `permissions` 结构，窄规则下
没有敏感字段、凭据赋值或令牌命中；其中 7 个版本包含上游工具使用的机器用户路径。
这些路径及命令正文不进入候选说明。逐个对象的本机审查记录保存在 ignored `target/`
内，不作为公开材料。

原始日志、XML 中的 properties/system-out、命令行、私有路径及整个 `target/` 都不属于
发布材料。历史测试事实只有经过 `scripts/check-delivery.ps1` 白名单重建的
`safe/summary.json` 可以作为安全摘要；旧来源摘要不能冒充版本变更后的新门禁结果。

## 承诺范围

本候选的第一步只固定交付内容、版本、归属和哈希。候选解包、构建与实际业务链路的
干净环境复现必须另留运行记录；没有新环境通过记录时，不得将候选打包成功写成验收
通过。真实部署还需独立解决凭据轮换、网络隔离、权限、备份、升级与回滚。
