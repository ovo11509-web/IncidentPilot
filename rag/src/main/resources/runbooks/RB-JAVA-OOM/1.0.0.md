## symptoms
来源症状：OutOfMemoryError heap oom 堆内存 内存耗尽。
候选解释：可能发生内存耗尽，不能据标题认定内存泄漏。

## evidence-required
必要前提：来源报告上述症状，service=incident-demo、environment=demo、resourceType=sim_service。
缺少指标或日志时不得将告警标题解释为已证实根因。

## checks-readonly
只读检查：核对 OOM 类型、GC 记录及只读堆观测。
禁止自动执行写命令。

## limitations
