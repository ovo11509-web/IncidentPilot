# 资源过载（模拟 Runbook）

IncidentPilot 自建模拟资料；非生产操作手册。

## symptoms
来源症状：cpu high load 负载 过载。
候选解释：可能存在资源压力。

## evidence-required
必要前提：来源报告上述症状，service=incident-demo、environment=demo、resourceType=sim_service。
缺少指标或日志时不得将告警标题解释为已证实根因。

## checks-readonly
只读检查：核对指标窗口、进程负载与请求流量。
禁止自动执行写命令。

## limitations
不操作真实基础设施；模拟结果不证明真实故障已修复。
